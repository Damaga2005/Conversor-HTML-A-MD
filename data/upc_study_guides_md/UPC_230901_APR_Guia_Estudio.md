## 5. Modelado Matemático y Fórmulas Clave (LaTeX)
### 5.1 Complejidad Búsqueda Binaria
$$
T(N) = T(N/2) + O(1) \implies T(N) \in \mathcal{O}(\log_2 N)
$$

### 5.2 Complejidad Ordenación por Inserción
$$
T(N) = \sum_{i=1}^{N-1} i = \frac{N(N-1)}{2} \implies T(N) \in \mathcal{O}(N^2)
$$

### 5.3 Aritmética de Punteros
$$
\text{addr}(arr[i]) = \text{addr}(arr[0]) + i \cdot \text{sizeof}(\text{type})
$$

### 5.4 Cota Superior Asintótica (Big-O)
$$
f(n) \in \mathcal{O}(g(n)) \iff \exists c > 0, n_0 > 0 : f(n) \le c \cdot g(n) \; \forall n \ge n_0
$$

### 5.5 Ecuación de Recurrencia Master Theorem
$$
T(n) = a T(n/b) + f(n)
$$

## 6. Banco de Ensayos / Laboratorio Virtual
```c
// APR - Algoritmo de Búsqueda Binaria y Gestión de Memoria en C
#include <stdio.h>
#include <stdlib.h>
int binary_search(const int *arr, int n, int target) {
    int l = 0, r = n - 1;
    while (l <= r) {
        int m = l + (r - l) / 2;
        if (arr[m] == target) return m;
        if (arr[m] < target) l = m + 1;
        else r = m - 1;
    }
    return -1;
}
```

## 7. Preguntas de Autoevaluación y Examen con Justificación Técnica
#### Pregunta 1
**¿La búsqueda binaria sobre un array ordenado de N elementos tiene complejidad O(log N)?**
- **Respuesta**: `[V]` (Verdadero)
- **Justificación Teórica**: Verdadero. En cada iteración el espacio de búsqueda se reduce a la mitad.

#### Pregunta 2
**¿El operador '&' en C obtiene la dirección de memoria de una variable?**
- **Respuesta**: `[V]` (Verdadero)
- **Justificación Teórica**: Verdadero. Es el operador address-of.

#### Pregunta 3
**El algoritmo de ordenación Bubble Sort tiene complejidad en el mejor caso O(1).**
- **Respuesta**: `[F]` (Falso)
- **Justificación Teórica**: Falso. Con optimización requiere O(N) para verificar que ya está ordenado.

#### Pregunta 4
**¿El paso de parámetros por valor en C crea una copia local que no modifica la variable llamante?**
- **Respuesta**: `[V]` (Verdadero)
- **Justificación Teórica**: Verdadero. Para modificar la variable externa debe pasarse un puntero a su dirección.

#### Pregunta 5
**Si un puntero a int (4 bytes) apunta a 0x2000, p + 2 apunta a la dirección 0x2002.**
- **Respuesta**: `[F]` (Falso)
- **Justificación Teórica**: Falso. La aritmética de punteros escala por el tamaño del tipo: 0x2000 + 2*4 = 0x2008.

#### Pregunta 6
**¿La función 'malloc()' reserva memoria contigua en el segmento Heap?**
- **Respuesta**: `[V]` (Verdadero)
- **Justificación Teórica**: Verdadero. El montículo (heap) gestiona memoria dinámica hasta la invocación de free().

#### Pregunta 7
**¿Una función recursiva sin caso base provoca un desbordamiento de pila (stack overflow)?**
- **Respuesta**: `[V]` (Verdadero)
- **Justificación Teórica**: Verdadero. Se acumulan marcos de activación hasta agotar el espacio del stack.

#### Pregunta 8
**En el estándar C, el tipo 'char' tiene un tamaño estrictamente dependiente de la arquitectura que puede ser 4 bytes.**
- **Respuesta**: `[F]` (Falso)
- **Justificación Teórica**: Falso. sizeof(char) es siempre 1 byte por definición del estándar.

#### Pregunta 9
**¿Las cadenas de texto en C deben finalizar obligatoriamente con el carácter nulo '\0'?**
- **Respuesta**: `[V]` (Verdadero)
- **Justificación Teórica**: Verdadero. Sirve como centinela de fin de cadena para todas las funciones estándar de <string.h>.

#### Pregunta 10
**¿Un algoritmo con complejidad O(N log N) es asintóticamente más rápido que uno O(N^2) para N grande?**
- **Respuesta**: `[V]` (Verdadero)
- **Justificación Teórica**: Verdadero. La tasa de crecimiento de N log N es muy inferior a la cuadrática.

#### Pregunta 11
**El operador 'sizeof' en C se evalúa exclusivamente durante el tiempo de ejecución (runtime).**
- **Respuesta**: `[F]` (Falso)
- **Justificación Teórica**: Falso. Es un operador evaluado en tiempo de compilación (salvo para VLA en C99).

#### Pregunta 12
**¿El bucle 'do-while' garantiza que su cuerpo de instrucciones se ejecute al menos una vez?**
- **Respuesta**: `[V]` (Verdadero)
- **Justificación Teórica**: Verdadero. La condición booleana se evalúa al final de la iteración.
